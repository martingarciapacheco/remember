# Inter 4.1

Unmodified static TrueType fonts from the author's official distribution:
https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip
Published download page: https://rsms.me/inter/download/

Copyright (c) 2016 The Inter Project Authors (https://github.com/rsms/inter).
Licensed under SIL Open Font License 1.1; see LICENSE.txt. Copies of that file
accompany the app executable, VST3 bundle and installer payload.

Regular and SemiBold provide body/control text. Inter Display Regular and
SemiBold provide headings at 20 logical pixels and above. No OS font installation
is required. Apple builds use San Francisco through the native system UI font.
